# M1 T01 工程质量基础

关联 HAR-003、HAR-004、HAR-005、HAR-010。无前置任务。状态见 [任务清单](tasks.json)。

目标是建立可执行的检查与交付机制，允许产品代码尚未建立。范围为项目本地工具依赖、统一入口、检查器和回归验证；本卡不交付产品 UI、API 或远端 CI。

验收标准：

- M1-T01-AC01：8 张任务卡均有需求映射、依赖和验收编号，清单结构检查通过。
- M1-T01-AC02：Python 和 TypeScript 工具代码通过真实类型检查，工具版本有锁文件，统一入口能生成带命令、时间、结果和作用范围的报告。
- M1-T01-AC03：正常样例通过；真实类型错误、跨层导入、契约漂移、伪造完成和依赖循环等反例被拒绝。
- M1-T01-AC04：复核及验证模板存在；产品缺失时 `m1` 返回 NOT_READY 与退出码 2，不能因工具自身通过而标记 M1 完成。

验证使用 `python scripts/check.py --profile harness` 和默认 M1 检查。工具测试只访问临时目录和模拟契约，不访问实际模型或设备。失败先修正检查器，不能削弱反例断言来获得通过。
