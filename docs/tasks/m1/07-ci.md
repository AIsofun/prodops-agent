# M1 T07 CI 接入

关联 HAR-005、HAR-009。依赖 M1-T06。状态见 [任务清单](tasks.json)。

根据实际代码托管平台配置 CI，使用锁文件安装工具并运行同一质量入口。先核对远端与平台，不假定本仓库一定具备某种云端权限。

验收标准：

- M1-T07-AC01：流水线使用固定运行时、冻结依赖和统一检查入口，保存实际执行结果，必要检查缺失不能视为成功。
- M1-T07-AC02：一次真实远端运行可追溯到代码版本；配置文件存在或本地通过不能替代远端证据。
- M1-T07-AC03：核对平台上必要检查是否限制合并，记录有效设置或未能启用的原因；没有权限时明确保持该部分未验证。

远端推送、账号或权限变更按任务已有授权办理，当前开发任务不自动授权发布产品或修改组织策略。
