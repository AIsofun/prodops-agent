# M1 T05 受限桥接与开发连接

关联 REQ-002、REQ-013、NFR-002、HAR-004。依赖 M1-T03、M1-T04。状态见 [任务清单](tasks.json)。

界面调用受限 preload 方法，由主进程连接开发 Python 服务并读取健康和能力数据。桥接与网络逻辑隔离，使用固定的已选择连接，不接受界面传入任意目标 URL。

验收标准：

- M1-T05-AC01：基础窗口能够通过实际桥接展示服务就绪、离线和协议不兼容三类状态。
- M1-T05-AC02：IPC 输入运行时校验、校验发送窗口、限定方法与连接范围；非法参数被拒绝。
- M1-T05-AC03：界面不直接持有凭据、不导入主进程代码；桥接具备行为测试和主进程连接证据。

随包 Python 的自动启动、随机端口握手和完整退出收尾在 M3 实现；M1 明确展示仍需手工启动的开发服务。
