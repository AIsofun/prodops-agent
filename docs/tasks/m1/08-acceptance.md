# M1 T08 集成验收

关联 REQ-001、REQ-002、REQ-003、HAR-005、HAR-010。依赖 M1-T06、M1-T07。状态见 [任务清单](tasks.json)。

核对开发窗口、Python 服务、桥接和契约整体工作，并检查文档与实际命令一致。M1 的结果为可开发、可验证的技术骨架。

验收标准：

- M1-T08-AC01：从明确的依赖安装步骤开始，开发窗口经受限桥接读取实际服务状态；启动、离线和错误场景有运行证据。
- M1-T08-AC02：M1 静态检查和远端 CI 有真实结果，验收范围及所有未验证部分明确；状态与实现位置一致。
- M1-T08-AC03：按统一模板完成复核和证据回执，更新需求追踪；不把骨架验收写成完整任务流、生产服务器或安装包完成。

验收后进入 M2 任务核心与 mock 排查。缺失的现场系统和性能数值仍在原需求规定的时点补齐。
