# M3 Windows桌面与本机部署

本阶段依赖[M2任务核心](../m2/README.md)，按[实施计划](../../implementation-plan.md)将服务能力接入真实桌面，建立启动、业务界面、事件、生命周期与离线包。任务依赖、需求与AC见[清单](tasks.json)，交付遵守[质量工作流](../../quality-workflow.md)。

| 任务 | 交付 |
| --- | --- |

| [M3-T02 业务桥接](02-bridge.md) | 有限IPC、认证网络与事件订阅 |

M2最终验收已verified，T01至T04已verified，当前下一任务为T05生命周期，其余任务按依赖推进。当前Windows11 AMD64仅作为开发验证环境，不推导为所有Windows平台承诺。干净电脑/虚拟机必须实际可用且符合验收条件；未取得该环境时不能把开发机隔离PATH检查写成已验证。签名、正式发布、升级与备份仍按M6及相关授权推进。

每项完成、验证与提交推送后按依赖自动继续。当前任务卡是已确认需求的细化，未来代码与证据逐项更新，不将设计当作已实现。
