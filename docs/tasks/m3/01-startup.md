# M3 T01 本机服务安全启动与握手

关联REQ-002、REQ-014、NFR-002、HAR-004。依赖M2-T06。状态见[任务清单](tasks.json)。

验收标准：

- M3-T01-AC01：Electron主进程定位开发/随包服务入口，生成随机令牌与实例标识，经继承管道传递；令牌不进入命令行、日志或renderer。
- M3-T01-AC02：本机服务随机回环端口，迁移/恢复完成后返回可校验握手；主进程验证实例、协议、健康与持久部署身份后才报告可用。
- M3-T01-AC03：启动超时、无效握手、端口/进程失败与父通道关闭在隔离子进程及实际桌面入口有证据，不自动掩盖失败。

本卡将既有M3需求与架构拆成工程实施切片，不新增产品范围。验证只使用隔离数据与明确模拟；真实模型、服务器正式身份、生产设备写入与外部发布不由本卡自动授权。
