## 构建与产物

在仓库根目录执行：

```text
uv sync --frozen --group dev --group packaging --cache-dir .quality-reports/uv-cache --link-mode copy
npm ci --ignore-scripts --no-audit --no-fund --cache .quality-reports/npm-cache
node node_modules/electron/install.js
npm run desktop:package
```

构建成功。Python3.13.2、Node24.14.1、Electron44.8.0、electron-builder26.15.3、PyInstaller6.22.3，依赖由uv.lock与package-lock.json固定。PyInstaller onedir包含独立Python服务，保留私有标准输入输出握手；显式收集aiosqlite动态依赖、迁移脚本及mock夹具。main打成单个CommonJS包，preload及renderer独立产物，不依赖仓库外部导入。资源定位由安装版resources路径确定。

本机产物位于忽略目录`.quality-reports/installers/ProdOps-Dev-0.1.0-windows-x64-setup.exe`，110032637字节；SHA256为`7030ef6c910e23682dd55617d2f7bd91c81884448e1f2cf2e26c95b11a374820`，另存[校验文件](2026-10-17-m3-t06-installed/installer.sha256)。安装包未提交Git、未签名、未发布。明确禁用证书自动发现及发布，构建时不继承签名凭据环境变量。实际Authenticode结果为NotSigned，见[安装记录](2026-10-17-m3-t06-installed/installation.json)。

包仅包含编译产品、Electron与冻结Python依赖；Python运行数据使用三文件白名单，不复制用户配置、数据库、模型权重或凭据。实际ASAR目录见[资源清单](2026-10-17-m3-t06-installed/payload.json)，不包含测试入口或开发依赖目录。开发图标为默认图标，签名、发布、自动升级和数据迁移策略仍属后续交付。

## 发现与修复

首次冻结启动暴露aiosqlite由SQLAlchemy动态载入而未收集；已显式hiddenimport并重新构建、重新安装验证。启动失败路径曾在未启动的存储上做结束核对；现在仅调度器成功启动后执行末尾核对，新增启动失败回归，保留原错误。PowerShell5检查进程/签名时使用系统模块目录，避免继承开发PowerShell7模块路径造成模块加载失败。

构建有Conda环境缺少conda-meta与未使用的tzdata/MySQLdb/pysqlite2可选模块警告；实际SQLite迁移、任务和重开成功，不把警告等同所有环境兼容。没有接入真实模型或生产设备。

上一提交5feaac5的[实际CI](https://github.com/AIsofun/prodops-agent/actions/runs/39001895106)失败：真实HTTP任务在固定100次、20ms间隔轮询结束时仍running，未达到succeeded；[原始记录](2026-10-17-m3-t05-remote/github.json)保留failure，不改写为通过。本轮改为15秒单调时钟有界等待，遇终态立即结束；仍要求成功、三条证据及unknown。此用例验证连接关闭后继续执行，不是两秒性能指标；性能门槛仍待NFR-005。后续提交CI另行观察，不把本地成功替代远端。

统一产品检查见[报告](2026-10-17-m3-t06-checks.json)，真实产品故障注入见[13项报告](2026-10-17-m3-t06-injections.json)。逐项AC：AC01构建与资源清单；AC02实际隔离安装/任务/重开；AC03锁定版本、哈希、命令、签名/发布状态及真实记录。复核见[记录](../reviews/2026-10-17-m3-t06-package.md)。
