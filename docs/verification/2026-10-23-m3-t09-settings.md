## 失败与修复

- 初次受限执行中，既有服务启动失败分支的进程回收检查失败并等待。只回收匹配本轮测试命令的测试进程树；获准环境中的完整检查全部通过，未修改目录权限或禁用 Electron 沙箱。
- 新增模型操作的 TypeScript 联合类型需要显式菜单分支收窄；初次编译失败后修正并编译通过。凭据入口的 CSS import 不符合现有边界解析器，改为 HTML 样式链接，边界检查通过。
- 初版滚动探针把长内容放在输入框后，遗漏隐藏辅助标签位于长内容之后的情形。实际打包长对话严格检查发现文档高度 1298、高于可视 684，标题栏仍为 0。为输入表单建立定位容器，并把长内容探针移到输入框前，保留严格断言后通过；没有仅隐藏错误或放宽几何条件。
- 保存后立刻编辑的 UI 用例曾超时：保存结果的偏好同步可能覆盖后续输入。设置表单改为首次可用时初始化，保存后保留当前编辑；最终实际 UI 全部通过。
- 早期打包探针在凭据 HTML 已出现、模块的表单处理器尚未初始化时提交，密钥状态等待超时。改为等待实际表单处理器初始化后操作，所有断言保留；未安装目录验证同时改为每次新建测试 profile，完整进程重开仍复用同次 profile。最终产物使用明确目录交付，之前失败包不作为验收产物。
