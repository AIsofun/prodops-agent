脚本不证明需求完整、诊断正确或验证证据内容充分，不检查网页外链是否持续可用，也不验证 Markdown 链接的页内锚点。已验证的 Harness 项只覆盖本记录描述的初始文档机制，后续持续维护仍需要在实际变更中执行规则。

产品需求保留未开始或待定状态；NFR-006 标为已实现，表示追踪机制建立，持续追踪质量尚需后续实现工作检验。HAR-010 为已建立的人工变更规则，不宣称已实现自动化执行。
