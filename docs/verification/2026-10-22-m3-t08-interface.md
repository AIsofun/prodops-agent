## 失败、重跑与未运行范围

- 最初受限执行无法读取 Electron 运行时，Windows 沙箱 ACL 检查阻止启动；同一受限执行的自建服务进程回收检查也失败。改为获准的测试进程运行环境后通过，没有修改目录 ACL、关闭 Electron 沙箱或关闭系统保护；检查未发现遗留握手模拟进程。
- 初版 UI 探针未等待 React 标签切换及截图页面挂载，分别出现“Invalid save overwrote previous draft”和脚本执行错误。修正探针等待实际标签、保存资料与页面挂载后，完整 create/reopen 验收通过；没有放宽产品输入校验或跳过断言。
- 此轮没有重新构建或验证安装包，也没有独立干净 Windows 验收环境；既有安装包不自动包含本轮界面。真实鼠标拖动、企业登录、真实模型协议/费用评测、云端密钥管理和服务器切换未验证。
