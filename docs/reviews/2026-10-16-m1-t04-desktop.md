# 桌面开发骨架复核

任务 M1-T04；REQ-001、HAR-003、HAR-005。基线 d90c0a4，复核桌面源码、Vite/TS 配置、开发脚本、smoke、锁文件及交付文档。Codex 实施 Agent 在首轮验证后逐文件 self_review，没有独立 Agent 或人工复核。依据为[任务卡](../tasks/m1/04-desktop.md)与[验证证据](../verification/2026-10-16-m1-t04-desktop.md)。

| 发现 | 级别 | 影响 | 状态 | 处理 |
| --- | --- | --- | --- | --- |
| R1 | P2 | 单一 CSP 会阻止开发态 Vite 样式和 HMR，或导致构建态放宽不必要权限 | fixed | 仅 serve 阶段转换 CSP，构建态保持严格策略；两种真实窗口均验证 |
| R2 | P2 | TS 导入 CSS 无法被现有静态边界检查解析 | fixed | 使用 HTML 的实际 stylesheet 引用，仍由 Vite 构建收集，没有放宽边界规则 |

复核实际主入口的生命周期、preload 运行格式、回环开发地址校验、导航及新窗口拒绝、权限拒绝、界面 Node 能力隔离、未实现按钮禁用与如实状态。独立 renderer 类型配置不提供 Node 类型。测试从正式主入口启动 Electron，截图来自实际 Chromium 渲染，不是浏览器替身；关闭后自然退出结果由外部启动器记录。

decision: approved，无 open 发现。仅本轮开发窗口范围；平台、正式安装包、服务管理、IPC、真实模型和远端 CI 尚未验收。后续任务继续建立实际桥接与服务连接。
