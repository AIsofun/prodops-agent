# 本机服务安全启动复核

M3-T01，基线dec70be加本轮工作区。Codex实施Agent单独self_review，无独立Agent或人工复核。对照[任务卡](../tasks/m3/01-startup.md)与[实际验证](../verification/2026-10-17-m3-t01-startup.md)，检查Python启动入口、DTO/生成器、主进程管理器及正式窗口装配。

| 发现 | 级别 | 状态 | 处理 |
| --- | --- | --- | --- |
| R1 | P2 | fixed | Windows虚拟环境启动器导致实际服务PID不同于直接子PID；采用显式父子关系并继续校验实例随机值、协议、部署身份和Bearer读取，实际Windows测试通过 |
| R2 | P2 | fixed | 故障注入需要收尾挂起子进程；启动失败先完成受控停止再向调用方返回，正常管道退出超时才回收自身进程树，不按名称终止其他进程 |
| R3 | P2 | fixed | 实际桌面测试使用隔离userData并检查绝对清理路径，避免将浏览器缓存、SQLite和本机状态写入版本化证据目录 |
| R4 | P1 | fixed | 全量检查暴露既有总超时中断状态提交的竞争；预算只取消工具等待，提交后取得新lease并在边界结算，确定性begin/finish提交延迟回归覆盖终态和会话释放 |

令牌由主进程随机生成，不进入启动参数或公共状态；启动管道有明确长度、版本和实例校验，响应同源Ajv校验且拒绝额外字段。主进程HTTP认证读取限制固定路径/端口/大小/超时，不跟随跳转，不自动重试。stderr和底层异常不暴露给界面。

服务使用独立随机回环socket，Windows排他绑定。迁移、恢复和调度装配后才发送就绪。私有父管道EOF及stop进入uvicorn正常lifespan收尾，OS服务锁覆盖该生命周期，数据库重开测试证明释放。失败信息固定，不回显非法输入。正常桌面退出等待服务停止。

decision: approved，无open发现。当前开发本机链路通过；随包运行时、托盘/单实例、强制结束完整策略、正式身份与安装包验收仍保留后续范围。
