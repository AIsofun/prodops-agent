# 托盘与服务生命周期复核

M3-T05；基线f6ed407加本轮工作区。Codex实施Agent单独self_review，无独立Agent/人工复核。对照[任务卡](../tasks/m3/05-lifecycle.md)与[证据](../verification/2026-10-17-m3-t05-lifecycle.md)，覆盖主入口、原生Tray、私有服务收尾及真实测试。

| 发现 | 级别 | 状态 | 处理 |
| --- | --- | --- | --- |
| R1 | P2 | fixed | 单实例锁先于服务准备，第二次启动仅show原窗口，不解析不受信任命令行或工作目录，不重复启动服务 |
| R2 | P2 | fixed | 关闭隐藏与明确退出分开；退出时主进程连接立即不可用于新业务，等待自有服务收尾后放行真正关闭并销毁Tray |
| R3 | P2 | fixed | 实际硬结束不能保证优雅代码执行，保留原未确认记录由真实重启扫描转待核对；单独验证EOF优雅路径而不混淆 |
| R4 | P1 | fixed | 服务关闭后所有worker已停且OS锁仍在时核对遗留执行意图；实际所有者失败和延迟中断写回归覆盖，避免正常结束后残留未核对running |
| R5 | P2 | fixed | 测试回执按本轮清理，PID必须匹配刚启动的父进程，失败也先回收已知自有进程，服务确认退出后才删除隔离数据 |

主进程仍只拥有自己创建的本机服务。Tray是主进程原生对象，不扩展renderer通用系统能力。窗口隐藏保留原React与IPC所有者；第二实例/恢复只显现并聚焦同一窗口。退出期间拒绝新业务，正常服务结束后关闭窗口；外部开发服务不会被此生命周期终止。

正常收尾的末尾核对只保守标unknown，不执行工具或自动重试未知写入；OS锁到数据库关闭后才释放。硬结束后的扫描与明确核对保留累计预算和旧unknown痕迹。实际父结束与端口/PID检查有证据，不将无进程推导为已撤销设备动作。

decision: approved，无open发现。干净Windows、安装包、正式图标/签名仍待对应阶段；原生交互验证使用实际对象/菜单回调，不冒称人工系统托盘点击。
